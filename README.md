## Week 9 vs Week 10 Comparison

| Feature | Week 9: Python Chatbot | Week 10: LangChain Chatbot |
|---|---|---|
| Implementation | Plain Python | LangChain framework |
| Language Model | Basic rule-based responses | Local Ollama LLM |
| Prompt Handling | Manual conditions | Prompt templates |
| Conversation Flow | Basic logic | LangChain chains |
| Summarization | Not available | Summarization chain |
| Question Answering | Basic responses | QA chain |
| Data Storage | Basic file handling | CSV using Pandas |
| Flexibility | Limited | More flexible and reusable |

## Observations

1. LangChain makes chatbot development more structured.
2. Prompt templates help organize instructions.
3. Ollama allows the chatbot to use a locally running language model.
4. Summarization and QA chains provide additional functionality.
5. CSV files help store prompts, queries, responses, and chain results.
